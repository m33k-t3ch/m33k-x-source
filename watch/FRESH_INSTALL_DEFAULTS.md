# Fresh-install defaults

For a clean device / erased NVS:

- Timezone: **Not set — choose**
- Wi-Fi SSID: blank
- Wi-Fi password: blank
- Stay Connected: off
- Clock display: 12-hour
- Phone/Web Dashboard: disabled/in progress
- C5 application link key: absent until first-time enrollment

Application-only flashing may preserve settings already stored in NVS on a developer device. That is expected and does not mean those values are embedded in source or in a freshly compiled firmware image.
